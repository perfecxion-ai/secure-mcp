# Changelog

## 2.0.0-alpha.3 (development)

Address the November 3 review findings in audit delivery, HTTP admission and request targets, access-token media types, startup diagnostics and request observability. See the [development notes](docs/releases/2.0.0-alpha.3.md). No frozen candidate or publication is claimed.

## 2.0.0-alpha.2 (held candidate)

Prepare installed-package onboarding, explicit Node patch enforcement, fresh consumer dependency evidence and a runnable triage/tool example. Preserve the [frozen candidate](docs/validation/ALPHA2.md) and its receipts unchanged while alpha.3 remediation proceeds. This candidate is not published to npm.

## 2.0.0-alpha.1 (GitHub prerelease)

Replace the experimental Socket.IO application with an official-SDK MCP runtime. Add stdio and Streamable HTTP, external token verification, explicit tool policy, bounded execution, workspace document reads, audit events, and clean package/container validation.

This incompatible alpha was published as a [GitHub prerelease](https://github.com/perfecxion-ai/secure-mcp/releases/tag/v2.0.0-alpha.1) and is excluded from npm promotion. Existing v1 installations require an explicit migration. The old implementation and test results are retained under `legacy/v1` and `docs/reviews`.

## 1.0.0 (historical)

The public GitHub release was published September 27, 2025. The former changelog used a conflicting January 9, 2026 date; its original content is preserved under `legacy/v1/CHANGELOG.md`. See the repository assessment for the reviewed baseline and release limitations.
