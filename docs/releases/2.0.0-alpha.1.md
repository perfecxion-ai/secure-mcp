# SecureMCP 2.0.0-alpha.1

Release proposal: GitHub prerelease, pending maintainer publication approval. npm publication is not included.

SecureMCP hosts approved MCP tools with scoped access, bounded execution, and content-free audit events. This alpha supports local stdio and authenticated Streamable HTTP through the official SDK. Included tools read approved documents, inspect policy, and optionally GET one operator-selected API destination.

## Install and validate

Use Linux, Node 24.22.1 or a later supported Node 24 security patch, and npm 11. Start with the [fresh-install guide](../validation/REAL_USER_VALIDATION.md): select Node explicitly, verify the handed-off bundle's digest through a trusted maintainer channel, install the tarball, and launch the real `dist/cli.js` using an absolute Node path. Local read-only use needs no paid service, database, or identity-provider account. Dependencies still require npm registry access during installation.

## Limits and support

This is experimental software for trusted handlers and operator-controlled workspaces. It is not an untrusted-code sandbox, upstream MCP gateway, prompt-injection detector, or security certification. Hard links and hostile local writers remain outside document confinement; populate read-only workspaces from trusted copies of approved files. Audit actor hashes are unsalted pseudonyms, not anonymization. Durable collection is bounded and has documented loss and retention limits.

Remote authentication uses an external issuer. Short token lifetimes and cached JWKS have documented revocation limits; issuer login, MFA, federation, recovery, and retention remain operator responsibilities. This prerelease does not establish production approval or a response-time SLA.

Use the repository's [private vulnerability reporting channel](https://github.com/perfecxion-ai/secure-mcp/security/advisories/new) for suspected authorization bypass, data exposure, or token leakage. Ordinary setup feedback belongs in the validation issue template with versions, digest, sanitized steps, and observed behavior.
